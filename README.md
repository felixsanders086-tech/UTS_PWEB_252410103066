
# UTS PWEB - Jember Explore

## Deskripsi
Website Pariwisata Jember merupakan website yang dibuat untuk memberikan informasi dan rekomendasi tempat wisata yang ada di Kabupaten Jember.

Website ini menyediakan informasi mengenai destinasi wisata, deskripsi tempat wisata, fakta unik, serta tautan Google Maps untuk membantu pengunjung menemukan lokasi wisata.

Website ini juga dilengkapi dengan fitur login, dashboard, profil pengguna, dan halaman pengelolaan data wisata.

## Teknologi yang Digunakan
- PHP
- Laravel
- HTML
- CSS
- Bootstrap
- JavaScript
